# Pain Complexity Education — paincomplexity.com

Single-page professional education site for clinicians, therapists, and care teams. Static HTML, no build step.

## Stack
- Single file: `index.html` (HTML + CSS + vanilla JS — all inline)
- Fonts: Google Fonts (Lora + Poppins)
- No dependencies, no framework, no build process

## Run on Replit
Workflow: **Start application** — `python3 -m http.server 5000`
Preview opens automatically at port 5000.

## Make changes
Edit `index.html` directly. Refresh the preview to see updates — no restart needed.
