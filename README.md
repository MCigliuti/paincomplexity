# Pain Complexity Education — paincomplexity.com

Single-page professional education site. Static HTML, no build step.

## Deploy (GitHub → Vercel)
1. Create a new GitHub repository (e.g. "paincomplexity").
2. Upload index.html (and this README) via Add file → Upload files → Commit.
3. Vercel: Add New → Project → import the repo → Framework preset: Other → Deploy.
4. Project Settings → Domains → add paincomplexity.com and follow the DNS instructions.
